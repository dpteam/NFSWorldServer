How to connect

  1. Start the server (run.cmd) or use the launcher.
  2. Open NFSWorldLauncher.exe, check the server URL, press Play.
  3. Manual launch: nfsw.exe US http://your-host:44600/Engine.svc a 1
  4. Create a driver name in-game; it becomes your persona.
  5. Invite friends: they only need this page URL and the launcher.
