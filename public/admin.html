Security model

  • The admin board refuses non-private IPs (web.adminPrivateOnly).
  • Every admin API call needs the token; failures are throttled and banned per IP.
  • The public board API never returns IPs, tokens, machine ids or logs.
  • Publish only the public port through NGinx Proxy Manager, over HTTPS.
